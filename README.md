# LangChain Models 🦜🔗

This repository contains my hands-on practice and experiments with **LangChain and Large Language Models (LLMs)** using Python. It explores how to integrate different language models, work with Hugging Face, and experiment with locally running AI models.

## 🚀 Topics Covered

- **LangChain:** Working with language models and building LLM applications.
- **Chat Models:** Exploring conversational AI models.
- **Hugging Face:** Loading and experimenting with open-source models.
- **Local LLMs:** Running models locally using Hugging Face Transformers.
- **Python:** Implementing and testing model integrations.

## 🛠️ Technologies Used

- Python
- LangChain
- Hugging Face Transformers
- Hugging Face Hub
- PyTorch

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   cd "Langchain Models"
   ```

2. Create and activate a virtual environment:

   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```

3. Install the required libraries:

   ```bash
   python -m pip install langchain langchain-huggingface transformers torch
   ```

4. Run your Python script:

   ```bash
   python ChatModels/huggingfacelocal.py
   ```

**Note:** Running models locally requires sufficient RAM and processing power. Model downloads require an internet connection initially, and performance depends on your hardware.
